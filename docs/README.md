## Что означает результат

Документация консолидирует исторические материалы и выделяет расхождения. В `apps/web` реализована демонстрационная версия интерфейса; действующие контракты, рыночные котировки и операции с реальными средствами не подключены. Новые правила бренда оформлены по мудборду; выбран логотип №7 и подготовлен его векторный мастер.

HTML работает без внешних библиотек и без сети. Поиск и фильтры каталога требуют JavaScript; при его отключении видны все материалы. Исходные архивы не изменялись. Папка assets содержит изображения без точных дублей; близкие, но различающиеся варианты сохранены. В PDF внедрён Open Sans, лицензия приложена.
