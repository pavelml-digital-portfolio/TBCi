# Версии

Техническое задание v1.1 от 30 октября 2026 — проект для оценки и разработки. Брендбук v2.1 — актуальный визуальный baseline, выбранный логотип №7 с бирюзовой точкой i и Open Sans Regular/Semibold.

Прежние архивы сборок удаляются только после проверки актуального комплекта. Исходные загрузки сохраняются. Никакие приложения ТЗ не являются отчётом о выполненных тестах приложения.

Изменение v1.1: по выбору пользователя сайт и кабинет объединены в один Astro-проект; отдельное React/Vite SPA исключено. Публичные страницы пререндерятся, приватные страницы Astro используют server adapter и React-компоненты, backend остаётся NestJS.
