# TBCi — техническое задание v1.1

30 октября 2026. Проект для передачи разработчикам и оценки. Брендбук v2.1 сохранён как визуальная основа.

- [ТЗ PDF — 38 страниц](TBCi-Technical-Specification.pdf), [Word](TBCi-Technical-Specification.docx), [Markdown](TECHNICAL_SPEC.md), [HTML](TECHNICAL_SPEC.html).
- [OpenAPI 3.1](openapi.yaml): 61 путь, 64 операции, 61 схема. Контракт ядра и базовых управляющих потоков; оставшаяся провайдерская детализация помечена явно.
- [Модель данных](DATA_MODEL.html), [схемы архитектуры](ARCHITECTURE.html).
- [133 требования](REQUIREMENTS.csv), [54 сценария приёмки](ACCEPTANCE.csv), [18 решений](DECISIONS.csv).

Сценарии приёмки ещё не исполнялись как тесты приложения. Часть решений — базовые предложения для проектирования, а фактические тарифы, провайдеры, сети, контрактные полномочия и другие параметры запуска требуют выбора заказчика. Они не подставлены из макетных значений.

Подключение реальных средств не следует из получения ТЗ. Документ позволяет оценить, декомпозировать и начать разработку на тестовых данных.
