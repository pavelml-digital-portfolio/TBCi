# TBCi — техническое задание v2.0

ТЗ полностью переработано по последнему **TBCI.rar**: 12 публичных макетов и 9 макетов кабинета. Для каждого зафиксированы исходный JPG, маршрут, блоки и поля, действия, состояния и приёмка. Старое ТЗ v1.1 заменено.

- [PDF с исходными макетами](TBCi-Technical-Specification.pdf), [Word](TBCi-Technical-Specification.docx), [HTML](TECHNICAL_SPEC.html), [Markdown](TECHNICAL_SPEC.md).
- [Сверка исходников с браузерной реализацией](REVIEW.html), [реестр 21 экрана](SCREENS.csv), [JSON](screens.json).
- [184 требования](REQUIREMENTS.csv), [50 критериев приёмки](ACCEPTANCE.csv), [18 решений и границ](DECISIONS.csv).
- [Модель данных](DATA_MODEL.html), [архитектура](ARCHITECTURE.html), [проект API следующего этапа](openapi.yaml).

Текущая реализация — статический Astro/React frontend, прямой вход в демо-кабинет, локальные операции. Серверный API, авторизация и реальные средства не подключены. Правила будущего backend отделены от требований к воспроизведению экранов. Состав, цены и адреса на старых макетах содержат противоречия; ТЗ явно фиксирует их и задаёт согласованную демонстрационную математику.

Брендбук Signal 07 и старый landing не являются визуальной основой этого выпуска.
