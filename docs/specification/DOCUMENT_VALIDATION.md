# Проверка документов ТЗ v1.1

Проверены комплектность, ссылки, нумерация и связи документов. Это не тестирование реализованного приложения.

- PDF: 38 страниц, 59 закладок; текст находится в границах страниц. Визуально проверены обложка, оглавление и примеры таблиц.
- 133 нумерованных требования, 54 сценария приёмки; все ID требований сопоставлены сценариям. Статус исполнения: not_executed_design_case.
- OpenAPI 3.1: 61 путь, 64 операции, 61 схема. Проверены внутренние ссылки, уникальные operationId и схемы JSON Schema; отрицательные проверки чисел вместо строк, нулевых/отрицательных/exponent amounts проходят как ожидаемый отказ схемы.
- 18 решений D01–D18 отделяют предлагаемый baseline от параметров запуска. Frontend: Astro SSG + React islands, кабинет в том же Astro-проекте с React-компонентами; backend NestJS.
- Контрольные суммы капитализаций, значение индекса и арифметика комиссий проверены независимо.
- Локальные ссылки HTML существуют; читаемость шаблона спецификации и таблиц проверена в Chromium на 320 px после добавления переноса длинных идентификаторов; локальный Open Sans загружается.
- Все 142 файла сохранённого графического комплекта совпали побайтно с последней сборкой v2.1.

Не выполнялись приложение, интеграции с реальными провайдерами, mainnet-операции и тесты контракта. Численные SLO и сценарии приёмки являются требованиями к будущей разработке.
