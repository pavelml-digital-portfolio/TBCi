# Фронтенд TBCi v0.2.0

Реализация заменена по **21 исходному JPG из TBCI.rar**: 12 публичных экранов и 9 экранов кабинета. [Маршруты и исходники](../specification/SCREENS.csv), [визуальное сравнение](../specification/REVIEW.html). Старый концепт и новая компоновка не используются.

Один Astro + React + TypeScript проект в apps/web. Публичные страницы генерируются в HTML; React обеспечивает фильтры, калькуляторы, графики и кабинет. Тёмная публичная шапка, исходные фотографии; светлое полотно кабинета с тёмным левым меню. Локальный Open Sans оставлен по ранее принятому решению заказчика.

Login/Register ведут прямо в /app/ без авторизации. Балансы, выбранный индекс, Buy/Sell/Compile/Unmake, пополнение/вывод и остатки поэлементной разборки сохраняются в localStorage этого браузера. Реальные переводы и серверный API не подключены. Все серии и цены — иллюстративные исторические данные. Подписка не отправляет email.

Публичные экраны: главная; страница индекса; каталог монет; Bitcoin Overview/Charts/Historical price/Markets/News; каталог бирж; Huobi; лента; статья Huobi. Кабинет: My Wallets, Choice index, Overview выбранного индекса, Buy, Compile, Sell, Unmake, Historical price (сравнение составов), Holders. Setting и FAQ — минимальные служебные страницы по ссылкам исходного меню; отдельных JPG для них нет. Дополнительные монеты/биржи/индексы используют те же шаблоны.

Проверки: npm run check; npm run build; npm run test:e2e; python3 -m unittest discover -s deploy/tests -v. 13 браузерных сценариев проверяют все 21 исходный маршрут, отсутствие ошибок, фильтры, расчёты, локальные операции, восстановление Claims после reload и адаптацию при 320/375 px. SCREEN_REVIEW.json фиксирует размеры снимков, pageerror и переполнения; высота динамического контента может отличаться от растрового примера.

Для обновления галереи: собрать приложение, запустить статический сервер на 4330 и выполнить node tools/capture-reference.mjs из корня. Можно задать TEST_BASE_URL и PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH. Галерея показывает исходный JPG и реальный браузерный снимок, а не выдаёт макет за готовую страницу.

Публикация — push в main, GitHub Actions Publish TBCi, Apache/vps-release на tbci.pavelml.ru. [Инструкция](DEPLOYMENT.md).
