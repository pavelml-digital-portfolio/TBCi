# Фронтенд TBCi

## Текущая версия

Единый Astro-проект в `apps/web`: 18 статических страниц, React-компоненты для интерактивности, TypeScript, локальные Open Sans и SVG-иконки брендбука v2.1. Встроенные изображения оптимизируются Astro в WebP. Самостоятельный блок «Динамика индекса» удалён с лендинга по согласованию; небольшая карточка индекса в первом экране сохранена.

## Публичные страницы

- `/` — первый экран, состав корзины из 20 активов, методология, публикации, демоформа подписки.
- `/articles/` и три статьи — материалы проекта, включая объяснение формулы индекса.
- `/privacy/` — информация о локальном хранении данных демоверсии.
- `/404.html` — страница ошибки.

## Личный кабинет

«Войти» открывает `/app/` сразу. Авторизация отсутствует по текущему заданию.

| Адрес | Возможности |
| --- | --- |
| `/app/` | Стоимость активов, график с выбором периода, структура портфеля, последние операции |
| `/app/wallets/` | Поиск, фильтр балансов, демопополнение и вывод |
| `/app/indices/` | TBCi 20 и состав корзины |
| `/app/buy/`, `/app/sell/` | Расчёт суммы и комиссии, выбор расчётного актива, подтверждение |
| `/app/compile/`, `/app/unmake/` | Расчёт 20 компонентов, проверка доступности, подтверждение сборки/разборки |
| `/app/history/` | Фильтры, детали операции, CSV, история состава |
| `/app/holders/` | Демонстрационные держатели, поиск, страницы, копирование, CSV |
| `/app/settings/` | Профиль, валюта, локальные переключатели, сброс демоданных |
| `/app/help/` | FAQ по операциям и деморежиму |

Все суммы, котировки, держатели и истории демонстрационные. Индекс в пунктах и цена токена в USD разделены. Покупка/продажа применяет комиссию 0,5%; сборка/разборка учитывает её в компонентах. Результат записывается в локальный журнал и меняет демонстрационные балансы. Доступ к blockchain, биржам и кошелькам не запрашивается.

Состояние хранится под ключом `tbci-demo-v1` в localStorage. Разные браузеры не синхронизируются. Кнопка сброса в настройках восстанавливает начальные значения.

## Проверка

На 30 октября 2026 года `npm run check` и `npm run build` прошли. Все **12 Playwright-тестов прошли** в Chromium: прямой вход, переходы по разделам, раскрытие состава, подписка, операции и комиссии, нехватка средств, сохранение, CSV, настройки и мобильная вёрстка на 320/375 px. Проверки сетевых операций и авторизации не входят в текущий фронтенд.

Повторный запуск — команды в корневом README. Скриншоты тестового запуска создаются в `apps/web/test-results/`.
