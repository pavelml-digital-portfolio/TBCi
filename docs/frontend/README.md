# Фронтенд TBCi v0.5.2

Реализация заменена по **21 исходному JPG из TBCI.rar**: 12 публичных экранов и 9 экранов кабинета. [Маршруты и исходники](../specification/SCREENS.csv), [визуальное сравнение](../specification/REVIEW.html). Первоначальные макеты сохранены как источник стиля; новая структура Overview/Wallet согласована отдельно.

Один Astro + React + TypeScript проект в apps/web. Публичные страницы генерируются в HTML; React обеспечивает фильтры, калькуляторы, графики TradingView Lightweight Charts и кабинет. Тёмная публичная шапка, исходные фотографии; светлое полотно кабинета с тёмным левым меню. Локальный Open Sans оставлен по ранее принятому решению заказчика.

Login/Register ведут прямо в /app/ без авторизации. Балансы, выбранный индекс, Buy/Sell/Compile/Unmake, пополнение/вывод и остатки поэлементной разборки сохраняются в localStorage этого браузера. Реальные переводы и серверный API не подключены. Все серии и цены — иллюстративные исторические данные. Подписка не отправляет email.

Публичные экраны: главная; страница индекса; каталог монет; Bitcoin Overview/Charts/Historical price/Markets/News; каталог бирж; Huobi; лента; статья Huobi. Кабинет: Overview со всеми индексами, встроенной торговлей и общей аналитикой; Wallet со всеми активами и переводами; Explore indices; Compile; Unmake; Historical price (сравнение составов); Holders. Старые Buy/Sell URL переводят в диалог Overview. Дополнены 32 статьи и отдельный календарь 48 ICO 2018. Settings расширен профилем, KYC, предпочтениями, 2FA, whitelist, историей, журналом и устройствами; FAQ содержит десять подробных ответов. Эти расширения поручены заказчиком, отдельных JPG для них нет. Дополнительные монеты/биржи/индексы используют те же шаблоны.

Проверки: npm run check; npm run build; npm run test:e2e; python3 -m unittest discover -s deploy/tests -v. 42 браузерных/модельных сценария проверяют 19 активных исходных маршрутов и два торговых URL-перехода, отсутствие ошибок, фильтры, расчёты, локальные операции, восстановление Claims после reload и адаптацию 320–2560 px. SCREEN_REVIEW.json фиксирует размеры снимков, pageerror и переполнения; высота динамического контента может отличаться от растрового примера.

Для обновления галереи: собрать приложение, запустить статический сервер на 4330 и выполнить node tools/capture-reference.mjs из корня. Можно задать TEST_BASE_URL и PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH. Галерея показывает исходный JPG и реальный браузерный снимок, а не выдаёт макет за готовую страницу.

Публикация — push в main, GitHub Actions Publish TBCi, Apache/vps-release на tbci.pavelml.ru. [Инструкция](DEPLOYMENT.md).

Расширение по последующему поручению: [анализ пустых областей и исправлений](CONTENT_AUDIT.md), [источники ICO/SVG](../sources/README.md). Векторы локальны, графики используют simulated OHLCV только 2018, статей 32 (более 350 слов каждая), календарь содержит 48 архивных записей и отдельные карточки. Вкладки Analysis/Trades/Forum/Timeline имеют самостоятельный контент. Тесты проверяют 320–2560 px и большие суммы на TBCi-50.
