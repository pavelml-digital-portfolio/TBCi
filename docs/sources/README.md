# Источники дополнений 2018

- ico-2018-source.json — URL исторической выгрузки, SHA-256, правила отбора и исключённые некорректные диапазоны; ico-2018-selected.csv — 48 выбранных записей без выдуманных дат/сумм.
- crypto-icons.json — 21 SVG, URL и SHA-256; cryptocurrency-icons-CC0.txt — лицензия.
- Новые редакционные тексты написаны для интерфейса самостоятельно. Проверенные первичные ссылки: [Bitcoin Core 0.17.0](https://github.com/bitcoin/bitcoin/releases/tag/v0.17.0), [ERC-721](https://github.com/ethereum/ercs/blob/master/ERCS/erc-721.md), [ERC-1155](https://github.com/ethereum/ercs/blob/master/ERCS/erc-1155.md), [EIP-1014](https://github.com/ethereum/EIPs/blob/master/EIPS/eip-1014.md).

Вторичная ICO-выгрузка может содержать ошибки или смешивать разные раунды. В интерфейсе это архивные reported values, со ссылкой на источник в каждой карточке. Отсутствующая сумма не заменяется выдуманным историческим результатом. Кольцо аллокации в карточке явно помечено как mock.

Модель KYC: официальные публичные TypeScript-декларации и README npm-пакета @sumsub/websdk; сопоставление событий/уровней и границы эмуляции описаны в [WALLET_KYC.md](../frontend/WALLET_KYC.md). Пакет не подключён к приложению.
