# Актуальные версии TBCi

- Брендбук **v2.1**: Signal 07, бирюзовая точка i, Open Sans Regular/Semibold; 46 иконок, 3 фона, 6 иллюстраций.
- Техническое задание **v1.1**, проект от 30 октября 2026: 38 страниц, 133 требования, 54 приёмочных сценария, 18 решений, OpenAPI с 64 операциями.
- Сводное описание исходных материалов v1.0 сохранено как происхождение требований и атлас исторических макетов.

Полная актуальная сборка: **TBCi-current.zip**. Предыдущие полные сборки заменены после проверки; исходные загруженные архивы сохранены. Тематический набор 30 иконок и logo v2.1 остаются отдельными актуальными выгрузками.

ТЗ не означает запуск операций с реальными средствами. Базовые технические предложения и неизвестные параметры запуска перечислены явно.

Frontend: единый Astro-проект — публичные SSG-страницы и приватные страницы кабинета с React-компонентами. Отдельного React/Vite SPA нет. Макет лендинга v1: design/TBCi-landing-v1.png.

Фронтенд v0.1.0 реализован в `apps/web`: 18 статических страниц, вход сразу в демо-ЛК, операции и настройки в localStorage. Авторизация и серверное API — следующие этапы. Самостоятельный блок «Динамика индекса» удалён. Проверки типов, сборка и 12 браузерных сценариев прошли локально и в GitHub CI. [Описание](frontend/README.md), [подготовленный деплой и текущий сетевой блокер](frontend/DEPLOYMENT.md).
