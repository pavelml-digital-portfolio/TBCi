# TBCi — графический комплект v2.1

Начать с [каталога assets.html](assets.html) или [брендбука PDF](TBCI-Brandbook.pdf).

- Выбранный логотип №7: новый мастер SVG с контурами, PNG с прозрачностью, основной PDF; четыре цветовых исполнения, знак отдельно — папка logo/.
- 46 иконок: 16 интерфейсных + 30 новых тематических. SVG, PNG 96×96, отдельные и общие sprite — папка icons/.
- Три фона PNG 1672×941 — backgrounds/.
- Шесть тематических изображений PNG 1672×941 — illustrations/.
- Брендбук полностью переработан: 24 страницы PDF; редактируемые Markdown, Word и HTML.

Текст TBCi в SVG переведён в контуры; точка i в цветных вариантах — #00CDEB. Основной текст и заголовки: Open Sans Regular/Semibold, без Light. TTF 400/600/700 приложены в fonts/; HTML загружает их локально через @font-face. Open Sans Bold использован для нормализации выбранного направления. Подпись из старого логотипа в новый знак не входит. Встроенные SVG-иконки управляются currentColor, PNG фиксированы в циане. Область нажатия интерактивного элемента — не меньше 44×44 px, даже если сама иконка 24 px.

Новые изображения сгенерированы для проекта и являются художественными метафорами. Их нельзя выдавать за реальные графики, данные о портфеле или подтверждение свойств сервиса. Фоны не являются бесшовными. Исходное разрешение не увеличивалось и не обозначается как 4K.

Логотип №7 выбран пользователем; прочие правила — рабочий стандарт этой версии. Старые исходники и макеты сохранены в общей документации, но их логотип не используется как действующий мастер.
