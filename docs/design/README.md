# TBCi — макет публичного лендинга v1

Десктопный визуальный концепт в TBCi Signal 07. Шапка, первый экран, график, состав корзины, методология, новости и подписка.

[Открыть PNG](TBCi-landing-v1.png).

Макет сгенерирован для обсуждения композиции; все курсы, даты, новости и веса демонстрационные. При реализации используются точный SVG логотипа и локальный Open Sans из брендбука, реальные тексты/данные — по ТЗ. Общая технологическая основа сайта и кабинета — единый Astro-проект.

При реализации самостоятельный блок «Динамика индекса» удалён по согласованию. В первом экране сохранена компактная карточка индекса. Актуальная реализация находится в `apps/web`; [описание фронтенда](../frontend/README.md). PNG сохранён как согласованный исходный концепт.
